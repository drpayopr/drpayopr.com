# DRPAYOPR accessibility maintenance and sign-off plan

**Owner:** DRPAYOPR website administrator (assign named owner before approval). **Target:** WCAG 2.2 AA.

1. Before release: review all changed pages, English/Spanish states, keyboard behavior, forms, dialogs, and consent; run automated checks and record evidence.
2. For new images, video, and PDFs: review contextual alt text, captions/transcripts, accessible PDF structure and form fields before publishing.
3. After deployment: test the live URL and third-party workflows, including Formspree and analytics consent; record date, browser/device and screenshots or reproducible notes.
4. For any failure: log an issue with impact, reproduction steps, owner, target date and WCAG criterion; fix, retest and document closure.
5. Reassess after material website changes and periodically (proposed quarterly; owner to approve cadence). Maintain an accessible feedback channel and update the public statement only when evidence supports its claims.
6. For external certification: commission a qualified independent evaluator, define audit scope and validity period, and publish only the exact claims supported by its findings.
